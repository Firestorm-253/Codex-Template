# .codex Index

This directory contains Codex operating contracts and mutable project memory.

Authority, edit rules, and required read order are defined in `AGENTS.md`.

## Contract files

- `PROJECT_OVERVIEW.md` — stable project-level context.
- `CURRENT_MILESTONE.md` — active milestone context.
- `CURRENT_TASK.md` — active task packet.
- `TDD_CONTRACT.md` — test-driven-development rules.
- `WORKFLOW.md` — per-task operating loop.
- `memory/INDEX.md` — memory directory map and memory update rules.

## Mutable memory files

- `memory/project_state.md` — current implemented state, test status, known issues, and last completed task.
- `memory/architecture.md` — current implemented architecture only.
- `memory/open_questions.md` — unresolved questions discovered during work.
- `memory/glossary.md` — domain terms and project vocabulary.
